# Практическое занятие №2. Менеджеры пакетов

При решении использовался Docker

## Задача 1

Команда для создания контейнера для дальнейшей работы
```
docker run --rm -it python:3.11-slim sh
```

Просмотр служебной информации matplotlib
```bash
pip show matplotlib
```

Установка пакета без использования пакетного менеджера pip
```bash
git clone https://github.com/matplotlib/matplotlib.git
```
